# CoFly USB / 3DR X6 地面站

参考 QGroundControl 的顶栏、侧栏与飞机设置布局，支持默认 USBSerial 直连或 3DR X6 透明串口无线连接。原 parameter_console 已整体迁入本目录，参数页和串口终端保持完整功能。

## X6 无线连接

在“通讯连接”选择 3DR X6，选择地面端 COM 口，默认 57600 / 8N1，无流控。天空端接 Teensy Serial8：TX→34、RX→35、GND→GND；天空端按 X6 实物标识与手册使用稳压电源，地面端通过 USB 连接电脑。详见 [接线、官方资源及协议迁移](../../docs/x6-radio.md)。

USB 与 X6 使用同一套 GCS/PARAM 协议，各自维护收发和参数列表状态；支持现有数据、构型和参数操作。自动连接同时识别 Teensy USB 和 X6 数传，初次选择优先 USB，详见下文“自动连接”。参数读取由原先八秒总超时改为八秒无合法 BEGIN/VALUE 进展超时，以支持较慢的无线串口。

## 启动

1. 将本版本 `.pio/build/teensy41/firmware.hex` 烧录到飞控，插入 SD 卡后重新上电。
2. 关闭占用串口的 PlatformIO/Arduino 串口监视器。
3. 双击 `dist/CoFlyGroundStation.exe`，无需 Python。源码运行双击 `start.cmd`，首次需要含 Tcl/Tk 的 Python 3；脚本创建 `.venv` 并安装 pySerial。
4. 在“通讯连接”页选择连接方式、COM 端口和波特率（USB 默认 921600，X6 默认 57600），点击连接，自动识别固件。
5. “参数”页点击读取参数，双击当前值编辑，Enter 提交、Esc 取消。EEPROM 参数仅在锁定时可改，普通 SD 参数解锁时也可改并先更新内存。EEPROM 在最后一次实际变动后 2 秒合并保存；SD 仅在锁定且最后变动满 2 秒后保存，解锁期间保持待保存，上锁后已到期则保存。状态栏显示等待及保存结果；失败保留内存值并重试。重启生效参数修改的是待启动设置，立即提示需要重启并禁止解锁。

旧固件仍支持参数页；数据和传感器页需要本版本固件。不同时运行旧控制台占用同一端口。

| --- | --- |
| 通讯连接 | 枚举/手动输入串口、波特率、连接/断开、能力识别与重试、重启飞控 |

| 串口助手 | 位于飞机设置最下方；接收日志、命令发送、十六进制显示、自动滚动、导出与原始记录 |
| 飞行 | 按机数显示独立姿态仪与欧拉角，本机角速度/加速度/空速及状态；底部滚转/俯仰斜视构型图 |

地速和高度没有有效来源，显示 `—`。飞行/遥控器/校准页最高 5 Hz 请求数据，两秒未收到有效数据则清空读数，其他页暂停轮询。全应用共用一个串口线程，参数事务与地面站请求互斥。设置保存在 `%LOCALAPPDATA%/CoFly/ground_station.json`，包含配色、字体、最近端口和波特率。

后台 DATA/CONFIG 读取不切换校准等操作按钮的启用状态。等待数据回复时点击操作会暂存一次，回复或超时后优先执行；实际参数事务、校准向导及其他操作期间仍按需禁用按钮，断开连接时清除暂存操作。

## 电脑参数文件

参数页“读取参数”旁提供“从文件读取”和“保存到文件”。先连接并读取完整参数；电脑文件使用与 SD `params.cfg` 相同的 V8 文本格式、版本/数量头部、名称:类型=数值记录和 CRC32，只包含声明在 SD 的参数，不含 EEPROM 的身份、校准或零点。

“保存到文件”将当前已读取/确认的内存值写到电脑选定位置，不访问板上的 SD。若某些值仅在 RAM 生效，导出的是这些当前值，内容可能不同于板上的旧文件，但格式完全相同。文件可以直接供其他板卡的 SD 加载器读取。

“从文件读取”校验 CRC、数量、名称、类型、范围和格式版本后，经 USB 逐项应用。若手动编辑导致 CRC 不匹配，只有其他检查全部通过才提示确认，选择继续后可导入；取消则不发送参数。CRC 尾缺失或格式无效仍拒绝导入。重新“保存到文件”会生成正确的 CRC，原文件不会自动修改。飞控直接读取 SD 文件仍严格校验 CRC。不同板卡和宏配置可共享参数文件，EEPROM 参数不修改；文件不带 UID、配置名称或 SD 代次。每项等待确认再发送下一项；失败或超时停止，不自动回滚已应用项。文件需与当前 SD 参数表完整匹配。只读参数必须与当前值相同，不发送写入。

## 传感器识别说明

返回固件编译配置与实际采样路径，未进行硬件健康检测。当前 `INTIMU + USE_MPU6050_I2C` 的初始化/主循环实际使用 BMI088 SPI，写入沿用的 `*_6050` 变量，因此显示 `BMI088_SPI`。

主循环还采样 MS4525 空速和 MT6701 转角。外置 IMU 受 `EXTIMU` 控制。BMP280 即便启用，主循环目前未调用 `getbarodata()`，显示 `INITIALIZED_NOT_SAMPLED`。磁力计/GPS/地速/高度未报告为有效。

MT6701 仅用于测量与 SD 记录，不参与构型显示或控制计算。翼尖相对角恢复为 tag0.1 默认路径的相邻 IMU 滚转差：AB=B−A、AC=C−A、BD=D−B、CE=E−C、DF=F−D、EG=G−E。OLED、USB、构型控制、控制分配、调试输出和数传均使用 IMU 角度；原 MT 日志字段保留。

空速和 IMU 尚无统一健康/测量时间戳接口，此处显示已有共享测量值；USB 帧新鲜度不代表传感器健康。

## 自动连接

应用设置中的“自动连接飞控”提供“是/否”，默认否，并保存在本机设置中。开启后在未连接时后台扫描，扫描结束两秒后开始下一轮，不阻塞界面。USB 候选依据 Teensy 标识，数传候选包含 CP210x、FTDI、CH340/CH341 等 USB-UART，以及用户选定端口；所有候选必须回复有效的只读 `GCS CAPS` 才会连接，USB 串口芯片本身不能证明它是 X6。

- 两种链路同时可用时优先 USB 直连；USB 无响应或被占用时尝试 X6。相同类型优先上次选择的端口，其余按端口名称排序。
- USB 默认 921600，X6 默认 57600，无流控。两类波特率分别保存并用于自动识别；数传配置与电台实际 UART 波特率必须一致。USB 识别等待最多 1.2 秒，数传最多三秒。
- 已连接时保持当前链路；数传连接期间插入 USB 不会强制切换。端口中断后自动重新扫描，重新按 USB 优先选择。
- 无线失联可能仍保留 COM 口，因此空闲页面每三秒发送一次只读 CAPS 检查；数据页利用原 DATA/CONFIG 请求检查。自动 CAPS/DATA/CONFIG 的发送与成功回复在串口助手中隐藏，手动查询、错误回复和飞控调试日志仍显示；“记录全部接收”保留完整原始字节。心跳成功不重复覆盖固件身份与操作状态提示。连续三次只读请求超时后断开并重新扫描。参数传输等操作期间不插入心跳，未确认的写参数、保存或重启操作不会自动重发。
- 手动断开暂停自动连接，在设置中再次选择“是”恢复；关闭自动连接不会断开现有连接。手动连接仍可指定端口。

## 多机姿态与实时构型

顶部为各机独立姿态仪，按物理顺序排列：单机 A，三机 B—A—C，四机 D—B—A—C，五机 D—B—A—C—E，七机 F—D—B—A—C—E—G。每框显示滚转、俯仰和偏航；只有 USB 连接的本机提供偏航，远端偏航显示 —。未收到或过期的机体姿态显示 — 和等待提示。空间不足时飞行页可垂直滚动。

下方采用翼尖连接的斜视翼面图，每片翼面根据本机实际 IMU 滚转和俯仰旋转：翼尖高低体现滚转，机头箭头相对于零俯仰虚线的偏移体现俯仰；文字同时显示各机俯仰。等翼展示意使用公共航向，不代表实际空间位置，不使用 MT6701。

`GCS CONFIG id` 保留 count、master、roll_a、ab/ac/bd/ce/df/eg、left_valid/right_valid、aircraft_id/config_valid，并追加各机 `r_a/p_a/v_a` 至对应机数（例如七机到 `r_g/p_g/v_g`）。r/p 为度，v 表示本机姿态或对应左右接收链路可用，不代表每个远端节点独立的新鲜度。完整构型需连接 A 主机，并且每机均有有效姿态；连接从机时可显示本机和可收到的下游机姿态，其余显示 —。

机间通讯保持原来的 34 字节状态帧、帧头 `55 71`，地面站 USB 服务直接读取已有滚转和俯仰结果，不增加或修改机间字段。直接左右链路超过一秒没有完整状态帧时失效；原协议无法独立判断外侧节点的新鲜度。USB 构型超过两秒或断连后清除姿态。旧固件仍可识别和读取参数，但缺少 USB 俯仰构型字段时提示更新。

## 重启与解锁保护

通讯连接页提供“重启飞控”按钮，仅在固件报告 `reboot=SUPPORTED` 后启用。必须先锁定飞机，未锁定时固件回复 `ERROR / LOCK_REQUIRED`。重启请求为 `GCS REBOOT id`，成功回复 `REBOOT / status=REBOOTING`；飞控发送回复后等待 250 ms，刷新日志，再进行软件复位。地面站收到确认后断开连接，重启完成后手动重新连接 USB。

任何标记重启生效的参数接受不同值并更新 RAM 后，OLED 立即全屏显示 `REBOOT REQUIRED`，保持锁定与安全输出直至重启；改回原值也不解除，延迟保存失败也不解除。相同值及被拒绝的修改不触发。

## USB 接口 v1

USB 和 X6 分别使用参数服务的 767 字节命令行缓冲，每周期每链路收发最多 64 字节，并按可写空间分片发送。各自参数列表完成前不处理该链路后续请求；每个串口只有一个读取者。

请求为 ASCII 行，LF 结尾，ID 是 uint32，响应为 `@COFLY\t{id}\t{kind}\t...\n`，与参数协议共用分片解析器。

```text
GCS CAPS 1
GCS DATA 2
GCS CONFIG 7
GCS REBOOT 8
GCS CALIBRATE 3 IMU
GCS SENSOR_SET 4 IMU DEFAULT
```

CAPS/DATA 返回 TSV 的 `key=value` 字段，定义见 `station_protocol.py`。数据包含 ms（板上毫秒，可回绕）、roll/pitch/yaw（度）、gx/gy/gz（度/秒）、ax/ay/az（g）、airspeed（m/s）、angle（度）、angle_valid、rc1..rc8（原始 μs）、n1..n8（[-1,1] 归一化指令）、mode、locked。桌面过期判断用本机单调时钟。

校准目标：IMU/GYRO/ACCEL、启用时的 EXTIMU、AIRSPEED、ROTATE。SENSOR_SET 接收单个 ASCII 设置标识，界面暂提供 DEFAULT。模式标识 MANUAL/STABILIZE 分别对应手动和增稳；积分由本机参数 `integralControlEnabled` 控制。

传感器校准和设置仍返回 ERROR / NOT_IMPLEMENTED；模式映射界面和命令已移除，模式由代码直接判断通道。接口位于 `src/ground_station_service/ground_station_service.h` 与 `src/ground_station_service/ground_station_service.cpp`。现有传感器按键/开机校准存在阻塞流程，未直接接到 USB。

参数协议和 SD 恢复见 [参数协议说明](PARAMETER_PROTOCOL.md)。[历史参数板上测试](BOARD_TEST_REPORT.md) 不代表本版地面站已完成板上验证。

## 遥控输入

八路分别使用 SD 参数 `RC1_MIN/MAX/TRIM/REV/DZ` 至 `RC8_MIN/MAX/TRIM/REV/DZ`，在参数页手动修改，沿用现有 SD 延迟保存。默认 MIN=1000、MAX=2000、TRIM=1500、REV=1、DZ=10（PWM 参数单位 μs）。TRIM±DZ 内输出 0，死区外按 TRIM 两侧有效行程分别缩放至 -1/+1，乘 REV 后限幅至 [-1,1]；REV 可为 +1 或 -1。各通道需满足 MIN < TRIM-DZ、TRIM+DZ < MAX。油门同样以 TRIM 为零点，进入推力混控时按 `(值 + 1) / 2` 换算为 [0,1]。

原有接收与 CH1–4 PWM 滤波逻辑保持原样，滤波后的原变量仅改名为 `radio_channelN_raw`，归一化输出为 `radio_channelN_normalized`。CH5–8 为辅助1–4。

## 遥控器九步校准

锁定飞机、打开遥控器并等待实时数据后，在“遥控器”或“校准”页点击“校准遥控器”。先弹出微调和辅助微调归零提示，点击确定后开始。通道顺序必须为 CH1 滚转、CH2 俯仰、CH3 油门、CH4 偏航。

向导依次提示：油门下拉、油门上推到底、油门下拉到底、偏航右到底、偏航左到底、滚转右到底、滚转左到底、俯仰下拉到底、俯仰上推到底。每步保持稳定至少一秒（至少六帧，波动不超过 12 μs），确认已到指定位置后点击“下一步”。第一步将其余三个主摇杆放在中位，采集中位值。两次油门低端须相差不超过 30 μs，每轴总行程至少 400 μs；方向由实际推杆时的 PWM 自动识别。俯仰下拉为正、上推为负；滚转和偏航右打为正，油门上推为正。油门中位使用上下端点平均值。

“下一步”按钮与实际采集使用同一组位置检查：只有稳定并符合当前步骤的端点、相对行程、方向及重复性要求才启用。主通道端点须进入 ≤1200 或 ≥1800 μs 的外侧范围，第一步的其余三轴中位须在 1300–1700 μs 内；第二步须离开第一步低端至少 400 μs，第三步须返回首个低端，后续每轴须离开中位且两端处于中位两侧。端点方向自动识别以兼容反向通道；PWM 本身不能证明机械限位，仍须按提示推到底。行程被缩小到无法进入外侧范围时按钮保持禁用。窗口默认固定为 520×220，启动时按所选字体大小缩放，不随提示文字长短变化。

完成后弹出“所有校准工作已完成，是否将新参数写入sd卡参数中？”。选择是才发送整组保存；选择否或中途取消不修改原参数。保存 CH1–4 的 RCn_MIN/MAX/TRIM/REV，保留死区和 CH5–8 参数。固件重新检查锁定和接收机状态，校验整组范围，写入并读回校验 SD 完整快照成功后才应用 RAM。失败保留原遥控 RAM 参数；成功后需重新读取参数页。普通参数的两秒延迟保存机制不变。

接收机主通道超过 250 ms 未更新、SBUS 失控/丢帧时禁止采样。短暂信号无效会暂停当前步骤并清空稳定采样，恢复后须重新保持稳定至少一秒；连续两秒无有效信号才取消校准。飞机解锁、USB 断开或数据中断仍会取消校准。USB 保存超时代表结果未确认，需要重新读取参数核对。地面站旧固件不显示可用校准入口。
