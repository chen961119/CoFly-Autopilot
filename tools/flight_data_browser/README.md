# CoFly Autopilot 飞行数据浏览器

参照 `flight_data_browser2.m` 的数据流程实现，读取飞控 SD 卡导出的数值日志，提供多文件曲线对比、子图、缩放/偏移、显示平滑、所选时间范围 FFT 和 CSV 导出。读取与分析逻辑在 `data.py`，窗口与命令行入口在 `main.py`。

## 启动

Windows 安装带 Tcl/Tk 和 pip 的 Python 3.10 或更新版本，双击本目录 `start.cmd`。首次启动会创建本目录 `.venv` 并安装依赖，需要网络；以后直接复用环境。已有环境缺少拖放依赖 `tkinterdnd2` 时，启动脚本会自动补装。

也可在仓库根目录手动配置：

```powershell
py -3 -m venv tools/flight_data_browser/.venv
& ./tools/flight_data_browser/.venv/Scripts/python.exe -m pip install -r tools/flight_data_browser/requirements.txt
& ./tools/flight_data_browser/.venv/Scripts/python.exe tools/flight_data_browser/main.py
```

macOS/Linux 使用 `python3 -m venv tools/flight_data_browser/.venv`，后续解释器路径为 `tools/flight_data_browser/.venv/bin/python`，并安装系统对应的 Tk 支持。

## 界面操作

1. 点击“选择文件…”打开系统原生文件选择窗口，默认显示 CSV 文件，支持 Ctrl/Shift 多选；可用文件类型筛选切换到 TXT/LOG/DAT 等其他飞行日志。也可直接将一个或多个文件拖入窗口，支持中文和带空格的路径。加载文件后不自动选择变量，手动选择后才绘制曲线。仅加载明确选择的文件；不支持选择或拖入文件夹。
2. 选择文件后记住第一个文件所在位置，下次打开选择窗口或重启工具后默认进入该位置。Windows 设置保存在 `%LOCALAPPDATA%\CoFly\flight_data_browser.json`，其他系统保存在 `~/.config/CoFly/flight_data_browser.json`；记录的位置不存在时回退到当前工作目录。文件树中选中文件或其变量后，用“上移”“下移”调整文件及曲线图例顺序，用“删除所选”从浏览器移除所选文件及其曲线；支持多选，原始文件保留。空搜索框显示灰色变量名搜索提示；在文件树中 Ctrl/Shift 多选变量可叠加到当前子图，添加子图后可为新子图选择另一组变量。
3. 选中变量，在缩放或偏移输入框按回车应用，得到 `显示值 = 原值 × 缩放 + 偏移`。输入框右侧上下箭头点击后直接生效：缩放上箭头乘 2、下箭头乘 1/2；偏移上箭头增加当前子图纵轴跨度的 10%、下箭头减少同样幅度（使用点击时的纵轴范围，包括滚轮缩放后的范围）。“恢复”只重置所选变量。曲线和 FFT 图例仅标出非默认的缩放倍数、带符号偏移量，例如 `[缩放 ×2, 偏移 -0.5]`；缩放为 1、偏移为 0 的项目不显示，应用或恢复后同步更新。
4. 默认在图内按住左键拖动即可平移，拖动开始前自动将对应时域子图设为当前目标。滚轮以鼠标位置为中心缩放：向上放大，向下缩小。时域子图共享时间轴，其范围限制为当前所有已绘制数据的完整时间范围：拖动不越过左右边界，滚轮或框选右键缩小到全时段后只继续缩小纵轴；纵向拖动仍可进行。FFT 图独立缩放和平移。
5. 勾选“区段 FFT”，对当前子图变量在可见时间范围内分析；缩放后自动更新。平滑只改变曲线显示，FFT 使用经过缩放/偏移的原始采样，不使用绘图抽稀数据。
6. 绘图工具栏依次为：后退、前进、恢复初始视图（房子）、框选缩放、设置、保存图片、CSV 导出。启用框选缩放后左键框选放大、右键框选缩小，再次点击关闭该模式；不再提供十字平移按钮。CSV 按钮导出当前子图中同一个文件的所选变量和可见时间段，附带秒时间列，保留原始数值，不应用显示缩放、偏移或平滑，也不能覆盖已加载的原始日志；跨文件曲线请分别选择后导出。

界面采用浅色分区面板，顶部显示文件数，绘图区显示子图与曲线数。左右分隔条限制两侧最小宽度，左侧按钮和输入框不会被挤掉；拖动时显示位置指示线，松开后调整比例。窗口连续缩放期间合并重绘，停止调整约 100 ms 后更新图表，不重新读取日志或计算 FFT。当前子图用蓝色标题和左侧坐标轴标识；未启用框选缩放时，左键单击时域子图可切换当前目标，同步更新子图下拉框、变量选择和 FFT 目标，与下拉框选择相同。曲线统一使用实线，同一变量在时域图和 FFT 中保持相同颜色，隐藏、重新选择或切换子图时保持一致。

每个文件以第一个有效样本为零点，**多机曲线没有自动校准绝对起飞时间或时钟差**。飞行区段由使用者自行判断，可通过工具栏缩放选择分析范围。

单击变量只选择当前变量；按住 Ctrl 点击可追加选择或取消选中，Shift 可连续选择。文件标题旁的加减号只展开或折叠变量列表，保留已选变量和曲线。跨文件多选时，可先选择 A 的变量、折叠 A、展开 B，再按住 Ctrl 点击 B 的变量，曲线会叠加到当前子图。

底部状态栏显示最近一次操作，包括点选/取消变量、文件展开折叠、搜索、子图切换、Zoom、平移、视图前进/返回、缩放偏移和显示选项；视图操作同时显示对应图块与坐标范围。自动重绘及 FFT 刷新不会覆盖操作记录，FFT 计算失败的原因显示在频谱图内。

“清除子图”位于“添加子图”和“删除子图”之间，清除当前子图的全部变量和曲线（含搜索隐藏的变量），保留图块和其他子图。“删除子图”移除下拉框当前选中的整个子图，剩余图块自动填满绘图区并重新编号。最后一个子图也可删除，不保留空白坐标轴；之后点击“添加子图”或重新选择变量可建图。

相同文件、大小、修改时间和读取选项不变时直接复用内存，正在读取的同一文件不会重复排队。文件读取在后台执行，其他窗口操作仍可使用；删除文件后未完成的旧任务不会重新填入界面。

偏航调参可搜索 `yawRateControlOutput`，对比 `proportionalTerm`、`integralTerm`、`derivativeTerm`、`feedforwardTerm` 和 `pidOutput`。四个分项均为已乘增益的混控尺度控制量，I 项已经限幅，四项之和为总输出；偏航控制未启用时均记录为 0。新字段按表头读取，旧日志不需要补列。

角速度指令统一以 rad/s 记录：`rollControlOutput.rateTarget`、`pitchPidControlOutput.rateTarget`、`yawRateControlOutput.rateTarget` 和 `configurationControlOutput.rateTargets[0..5]`（AB、AC、BD、CE、DF、EG）。滚转／俯仰 PID 记录外环限幅及滤波后的内环指令，俯仰含耦合补偿；偏航记录叠加协调转弯前馈后的指令。构型指令对应相邻两机的相对滚转角速度，滚转编队指令对应平均滚转角速度反馈。未启用的控制器指令清零；滚转阻尼 `rollDampingControlOutput.rateTarget` 固定为 0。俯仰 INDI 沿用已有 `pitchIndiControlOutput.q_ref`，不另加重复列；油门控制沿用 `throttleControlOutput.airspeedTarget`（m/s）。

## 命令行与复用

以下命令在本目录的环境中执行；把 `python` 换成 `.venv/Scripts/python.exe`（Windows）或 `.venv/bin/python`（macOS/Linux）。

```sh
python main.py datalog109.csv --summary
python main.py A/datalog109.csv B/datalog064.csv
python main.py datalog109.csv --fft "att[0](deg)" --from 30 --to 60
python main.py datalog109.csv --summary --time-column "TimeStamp(us)" --time-unit us
python main.py damaged.txt --summary --skip-bad-rows
```

`--summary` 输出 JSON：行列数、持续时间、实际采样率、内存、时间来源和读取提示。可以用 `--encoding gb18030` 指定旧编码，用 `--delimiter ";"` 指定分隔符。找不到时间列时使用 `--fallback-hz`，默认 50 Hz，并明确报告该假设。

在其他 Python 程序中把工具目录加入模块路径后，可直接调用：

```python
from data import load_log, compute_spectrum

log = load_log("datalog109.csv")
roll = log.column("att[0](deg)")
fft = compute_spectrum(log.time, roll, bounds=(30, 60))
print(log.sample_rate, fft.peak_frequency)
```

## 读取与分析优化

- 首行为表头，每条数值记录占一行；支持逗号、制表符、分号以及 UTF-8 BOM。括号单位保留，重复/空白列名自动生成不冲突的名字。
- 常规文件通过 pandas C 解析器分块读取（默认 32,768 行），同时校验每行列数，最终每个日志保存独立 float64 数组。不同长度的多机数据不拼成填满 NaN 的大矩阵。
- 表头与数据宽度不一致直接报错，避免旧版按列数截断后错配字段。无效数值/坏行默认报错；通过命令行传入 `--skip-bad-rows` 后才用宽容读取并报告物理行号。空白字段保留 NaN，不补零。宽容回退比正常路径慢，适用于损坏文件。
- 时间单位优先服从表头或显式设置；仅未标单位时按增量推断并提示。使用真实中位采样间隔估计采样率，识别 Teensy uint32 微秒计数器回绕。重复时间戳保留第一条，缺失时间戳删除对应行并提示；普通倒退/复位报错，不能静默排序成一次连续飞行。
- 显示按当前视窗保留每个区间的极小值、极大值和缺口，通常约 6,000 点。缩放后从原始数据重新抽取，避免均匀抽点漏掉窄脉冲；不修改原始数据，也不为了画平滑线插值到四倍点数。
- FFT 去均值，使用 Hann 窗和单边幅值归一化。根据所选区段的真实间隔处理抖动与短缺失，必要时重采样并标注；大于五个采样周期的缺口拒绝分析，需缩小区段。最低八个有效样本。

全量原始数据仍保存在内存中，内存量约为 `行数 × 列数 × 8` 字节，加上时间轴和加载期间临时缓冲；分块解析不代表完全不占内存。数据必须是带表头的数值表，不支持二进制遥测或跨行文本单元格。当前固件 `logFlightData()` 在单机和编队下使用统一表头；旧日志列数不匹配时应先修正日志格式，工具不会猜测列含义。

## 验证

按项目要求，测试脚本在验证后删除；下面保留此前验证的覆盖范围及结果记录。

数值测试覆盖时间单位、重复/缺失时间、uint32 回绕与复位、坏行与分块边界列数、重名表头、模式缺失值、正弦幅值、FFT 抖动/缺口和窄脉冲显示。界面集成测试在隐藏窗口验证后台多文件加载、变换、搜索、FFT、子图和空视窗。

2026-10-10 本机验证：13 项测试通过；七机实际日志（约 348 MB，均为 117 列）全部读取成功，一次顺序读取与预处理合计约 5.9 秒。其中约 57 MB 的 A 机日志包含 79,291 行，读取与预处理约 0.9 秒。该测量受硬盘和系统缓存影响，不是与 MATLAB 的速度对照。七机时间戳的中位采样率均约 45.45 Hz，程序保留实际时间及抖动提示。

MATLAB 参考文件作为实现参考读取，原脚本与原始飞行日志不修改，也不复制到仓库。

当前飞控日志列名直接使用代码变量名：`current_time` 固定按微秒读取，`att[0]` 等不附单位别名；遥控列为 `radio_channel1_normalized`～`radio_channel8_normalized`，范围 [-1,1]，保留六位小数。`currentFlightMode` 和遥控通道均可作为普通变量选择绘图。旧 `TimeStamp(us)`、`RC_CHx` 和 `CHx_PWM` 日志仍兼容读取。

当前固件日志中，`att` 为 rad、`ang_vel` 为 rad/s、`ang_acc` 为 rad/s²、`acc` 为 m/s²；INDI 和构型全局字段已去掉度制后缀。浏览器直接显示原始数值，不自动转度。时间和 PWM 单位保持原约定；上述带 `(deg)` 的命令示例用于历史日志。完整字段迁移见 [全局变量 SI 迁移报告](../../docs/global-si-migration.md)。
