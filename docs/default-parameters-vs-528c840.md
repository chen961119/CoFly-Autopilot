# 当前工作区与 528c840 的默认参数计算对比

> 历史采样记录。2026-10-27 的更密集逐周期复核见 [当前版本与飞行 tag 的对比](control-comparison-20261024-3Airplane-Flight.md)：默认三机 PID 也存在 1 μs 边界差异，本文“本次采样全部相同”不代表任意输入、任意周期严格相等。

## 结论

当前工作区与基准提交 `528c840b04296e903bf9f42cbf5d01fbae19a33c` 分别使用各自源码默认值，直接编译并运行实际控制器、主从控制入口与混控代码。本次不修改生产代码，不加载 SD 参数，不人为设置 PID/INDI 控制器输出，也不复用此前版本的计算结果。

- 默认三机、策略 1、PID：本次所有板级采样状态的五路最终整数 PWM 与基准全部相同。
- 手动模式：包括所有扩展机数和策略，最终整数 PWM 全部相同。
- INDI：副翼滚转/构型主分配按已确认的需求变为基准的 2 倍，其他贡献保持等效。默认三机/策略 1 下扣除该预期变化后，整数 PWM 残差为 0。
- 扩展到 1/3/4/5/7 机和三种策略后，扣除 INDI 预期变化，最大整数 PWM 残差为 1 μs。升降舵、油门、方向舵在本次所有采样中的整数 PWM 均相同。

以上是所列输入的计算结果，不代表所有可能输入逐位相等。

基准从指定完整提交重新导出；不是从历史测试目录或当前工作区反推。当前 Git HEAD 仍是该提交，比较对象是包含未提交修改的当前工作区。

为观察控制计算，测试假定飞机身份已经配置并处于解锁输出状态；未配置身份、上电锁定时的安全位置输出不在这些动态计算场景中。

## 采样统计

每组场景运行 250 个 2 ms 周期，在第 0/1/4/9/24/49/99/149/199/249 周期记录。6 类场景包括零误差、滚转阶跃、俯仰阶跃、构型阶跃、动态耦合与刹车、饱和及积分限幅。手动/PID/INDI、三种策略、两个 PWM 配置均使用相同输入。扩展五种机数后，每版运行 540000 次板级控制更新，合计记录 21600 对板级采样状态及 108000 对最终整数 PWM。

“预期变化后残差”只在 INDI 模式按 `当前总副翼贡献 = 基准总贡献 + 基准滚转/构型主分配` 计算；保留交联、阻尼、刹车和前馈，然后按原 PWM 映射和物理限幅复算。其他模式直接与基准相减。

## 方法与边界

实际编译两版的 `runMasterController()`、`runSlaveController()`、各控制器、主从 mixer、目标生成、融合及 PWM 映射/限幅函数。每块飞控拥有独立控制器历史；从机使用主机实际生成的 `SlaveCommand`，而非固定注入的上级贡献。反馈和遥控目标是预设物理序列，未建立飞机动力学闭环模型。

机间在数值程序内直接传递浮点命令，不模拟串口延迟和定点量化；未连接实机、未烧录。主机编译使用与板端一致的 math.h 浮点绝对值语义，并启用 -ffast-math。移除旧 57.3 近似及弧度计算中的舍入次序，会留下微小浮点差异；扩展测试的 1 μs 整数边界差异如上单独列出。
