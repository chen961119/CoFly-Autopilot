# 控制输出尺度与弧度换算核对

后续默认目标与参数修改后的实际 PWM 结果见 [最新工作区复核](control-comparison-20261027-latest.md)；当前默认 PID 最大差异已超过 1 μs，不能沿用下述历史快照结论。

2026-10-27 上一轮与飞行 tag 的逐周期主从核对见 [历史差异报告](control-comparison-20261024-3Airplane-Flight.md)。该快照默认 PID 物理尺度等效，但发现最终整数 PWM 的 1 μs 残差；保留纯弧度实现，不宣称严格相同。

当前工作区与完整提交 `528c840b04296e903bf9f42cbf5d01fbae19a33c` 各自默认参数的直接计算结果，见 [默认参数计算对比](default-parameters-vs-528c840.md)。该报告区分源码默认 ±500 μs 与配置 ±200 μs，并使用真实主机输出驱动从机计算。

## 基准与范围

以当前提交 `528c840`（Scale PID actuator allocations before mixing）为 PID 行为基准；按后续明确选择，INDI 的滚转/构型副翼主分配采用与 PID 相同的尺度，允许相较该提交增加 2 倍。不把前一版未提交的输出增益方案作为基准。没有新增控制输出字段，也没有新增可调参数；所有补偿合入现有控制参数和对应分配公式。

tag `0.1` 在 `scaleCommands()` 中先计算 `1520+1000*u`，但之后副翼还经过 `(PWM-1520)*0.4`。忽略饱和、整数截断和配平差异，副翼真实主分配斜率为 400 μs/u，升降舵为 1000 μs/u。

| 原控制作用 | tag 0.1 增量 | 528c840，单侧行程 200 μs | 本次修改 |
| --- | --- | --- | --- |
| PID 副翼原分配 0.1 | 1000*0.1*0.4 = 40 μs | 200*(2*0.1) = 40 μs | 控制器输出换为 0.2，直接映射为 40 μs |
| PID 升降舵原输出 0.1 | 1000*0.1 = 100 μs | 200*(5*0.1) = 100 μs | 控制器输出换为 0.5，直接映射为 100 μs |
| INDI 要求 PWM 偏移 100 μs | 物理 PWM 控制 | 归一化为 0.5，再正向映射回 100 μs | 保持物理逆映射，不能再乘 2 或 5 |

这只说明对应未饱和贡献的斜率，不声称旧 tag 的符号、配平、限幅、交联、偏航控制律等全部等同当前提交。此前把副翼也按 1000 μs/u 推导并增强 2.5 倍的方案已撤回。

## 弧度与现有参数

令 R=`Units::toRadians(1.0f)`。角度值直接使用 `Units::toRadians(原度数)`，按角度倒数定义的增益则除以 R。滚转、俯仰、构型和 INDI 内部目标、误差、滤波历史、角加速度及积分均使用弧度，不再先转成度计算。遥控 maxRoll/maxPitch/maxYawRate 和 Trim_pitch_angle 仍在目标生成边界从显示用度转成弧度；IMU 标定原始零偏的介质单位不变。

| 原参数或比例 | 新参数值 |
| --- | --- |
| Kp/Ki_roll_angle、Kp/Ki_pitch_angle、Kp_Flap | 旧值*30，去掉外环额外乘 30 |
| 滚转、构型内环 P/I/D/FF（存在的项） | `旧值 * 0.02 / Units::toRadians(1.0f)`，去掉 0.01，同时合入原副翼乘 2 |
| 俯仰内环 P/I/D/FF | `旧值 * 0.05 / Units::toRadians(1.0f)`，去掉 0.01，同时合入原升降舵乘 5 |
| 五项乘 Ki 前的误差积分限幅 | `Units::toRadians(旧值)`，默认 `Units::toRadians(45.0f)` |
| k_Clp | `旧值 * 0.00625 / Units::toRadians(1.0f)`，直接产生最终归一化阻尼 |
| indi_pitch_pwm_to_rad_k | `Units::toRadians(原 indi_pitch_pwm_to_deg_k)` |
| indi_pitch_rate_limit_rad_s | `Units::toRadians(原 indi_pitch_rate_limit_deg_s)` |
| indi_pitch_effectiveness | 不变，(deg/s²)/deg 与 (rad/s²)/rad 比值相同 |
| 偏航与空速参数 | 保持当前提交，不再次换算 |

参数直接采用当前弧度值，不提供旧参数名称别名、旧值自动换算或控制单位版本标记。两项含 deg 的 INDI 参数一对一改为 rad 名称，参数总数不变。上表仅说明源码中参数值的换算关系，不在加载或电脑导入时执行。

## 混控、前馈和 INDI

主从 mixer 取消末尾统一缩放。本机交联和刹车仍在最终归一化坐标中使用。滚转参与差动油门时按原控制作用换算；滚转和构型参与从机目标角时直接修改对应弧度系数，没有额外发布协调输出。三机策略 3 的升降舵前馈按对应位置计算，PID 保持原先补偿 5 倍，INDI 保持当前提交未补偿的行为。

528c840 的副翼整体乘 2 受俯仰 PID 选择控制，INDI 时原本没有这一步。按后续明确选择，已移除 INDI 分配入口对滚转/构型控制量的减半处理，增稳 PID/INDI 统一使用相同尺度。因此 INDI 模式的副翼主分配为该提交的 2 倍，且只改变这一贡献；本机升降舵 INDI、交联、阻尼、刹车、油门、方向舵、从机目标和升降舵前馈保持此前的响应。饱和后的最终 PWM 仍受 min/max 限制，不能把最终 PWM 或含其他贡献的总偏移简单乘 2。

INDI 使用物理 PWM 的 min/trim/max 推导舵角界限，再通过同一映射归一化。因此改变 min/max 后，同一可实现的物理舵角命令仍能逆映射回相同 PWM；可实现范围随真实行程改变。min/trim/max 非对称或 rev=-1 时也分别按物理两侧处理。内部舵机模型仍只包含本机 INDI 命令，不含后来融合的上级前馈。

## 验证方法

分别编译 528c840 与当前源码的原生数值程序，覆盖 1/3/4/5/7 机、三种策略、手动/PID/INDI 切换、积分开关、两个安装方向、四组 PWM 标定（含 trim±200 μs 和非对称行程）。

第一层注入相同控制作用，并按新接口定义对应滚转/构型为旧数值的 2 倍、俯仰 PID 为 5 倍、阻尼为 5 倍，直接比较两版主从逻辑输出、目标角和最终限幅 PWM，不给旧版结果额外乘增益来通过检查。第二层输入相同物理目标和测量运行完整控制器，比较实际 PWM，单独记录将旧 57.3 近似换成真实弧度后的微小差异。

## 弧度化阶段核对结果（副翼尺度统一前）

- 参数表保持 149 项。`control_types.h`、日志输出字段和已经使用弧度的偏航角速度控制器相对 528c840 没有改动。
- 5 种机数共 7200 组场景、3823200 项数值比较通过。同一控制作用的混控浮点 PWM 最大差为 0.00013 μs；完整控制器响应最大差为 0.02735 μs。
- 同一控制作用的固定输出核对中，最终整数 PWM 全部相同，差异样本为 0。完整控制器响应核对中有 349 个整数边界输出存在 1 μs 差异，最大不超过 1 μs，来自弧度化及浮点计算次序变化。因此混控尺度保持等效，完整动态响应不承诺逐位相同；不再有额外 2.5 倍增益变化。
- 旧控制参数兼容、单位自动换算和相关格式标记已按要求删除；固件和地面站直接按当前参数值读写，当前格式的固件保存/加载和电脑导入/导出往返检查通过，数值不自动缩放。
- Teensy 4.1 Release 和 Debug 编译通过，`git diff --check` 通过。未烧录硬件。

原生测试环境显式包含 math.h，与 Teensy 的浮点 abs 重载一致；另用板端编译器核实 abs(float) 生成浮点绝对值，避免把主机头文件差异误判成飞控行为。

## PID/INDI 副翼尺度统一与角度常量写法

增稳分配直接使用归一化滚转与构型输出，不再根据俯仰选 PID/INDI 而减半。保留手动分配原行为，不新增参数或控制输出字段。角度阈值、角速度限值、从机目标系数、积分限幅及 INDI 标定/限速常量统一使用 `Units::toRadians(原度数)`，例如 `Units::toRadians(20.0f)` 和 `Units::toRadians(240.0f)`，控制状态及积分仍使用弧度。

最终版本与尺度统一前的弧度版本逐项对比，覆盖相同 7200 组场景及 3823200 项数值；检查 INDI 模式中仅主副翼分配乘 2，先分离并保留交联、阻尼和刹车，再按真实映射及物理限幅核对 PWM。其余模式、通道、目标、前馈和本机闭环输出保持等效。全部检查通过，5600 行 INDI 测试记录匹配预期，最大绝对比较误差 0.0001271。此处的 2 倍是用户明确选择的 INDI 副翼变化，不属于之前错误的额外 2.5 倍增益方案。

## 参数表达式可读性核对

默认值、参数范围和参数列表说明均使用 `Units::toRadians(...)` 表达单位来源；逆角度增益采用 `分子 / Units::toRadians(1.0f)`，例如滚转 P 为 `0.003 / Units::toRadians(1.0f)`，对应上限为 `0.2f / Units::toRadians(1.0f)`。角度常量及增益的换算方向不同，不把这些逆角度增益直接乘 pi/180。

Debug 与 Release 数值程序分别逐位核对 55 个浮点默认值和 100 个注册表范围边界，155 项均与表达式改写前一致。这里只改善数值来源与参数说明的可读性，不改变控制强度，不增加参数或兼容逻辑。
