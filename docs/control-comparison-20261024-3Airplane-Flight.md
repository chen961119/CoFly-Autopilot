# 当前版本与 20261024-3Airplane-Flight 的主从控制／混控对比

> 这是上一轮工作区的历史快照结果。后续构型目标、D、阻尼和积分限幅已修改，当前默认 PID 差异不再仅为 1 μs，见 [最新工作区复核](control-comparison-20261027-latest.md)。

核对日期：2026-10-27。tag 解引用后为 `528c840b04296e903bf9f42cbf5d01fbae19a33c`；当前源码 HEAD 为 `125f1bd`。本次保留纯弧度控制实现，生产代码及参数没有修改；新增差异报告和可复现程序。

**默认 PID 的控制强度和混控尺度等效，但最终整数 PWM 并非严格相同。** 本次默认三机／策略 1 的 12,000 对板级逐周期样本中，48 对出现 1 μs 差异；没有发现更大的 PID 整数 PWM 差。用户选择保留纯弧度并记录残差，因此“所有相同输入输出完全相同”的严格目标未达成，也没有将 ±1 μs 重新定义为严格通过。

## 默认参数和比较条件

两版各自使用源码默认参数，不加载 SD/EEPROM 参数文件，也不把旧增益直接装进新版本。

| 项目 | 两版配置 |
| --- | --- |
| 默认机数／策略 | 三机／策略 1 |
| 俯仰算法 | PID，`pitch_controller=0` |
| 积分／空速控制 | 积分启用，空速闭环关闭 |
| 五路 min / trim / max | 1000 / 1500 / 2000 μs，即舵面单侧 500 μs |
| 五路 mode | 均为 0 |
| 五路 rev | -1 / +1 / +1 / +1 / +1 |
| 俯仰目标配平 | 3° |
| 身份、锁定 | 显式配置 A/B/C，解锁以观察动态输出 |

源码身份默认为未配置、系统上电锁定；本报告研究配置身份并解锁后的控制行为。mode=0 油门输入 0.5 对应 1750 μs，两版相同；未把油门映射私自改成 mode=1。

## 主机：控制与混控对应关系

令 R=`Units::toRadians(1.0f)`。不能只比较裸参数或控制器发布值，需连同下游分配倍率检查。

| 控制作用 | tag | 当前版本 | 对实际 PWM 的影响 |
| --- | --- | --- | --- |
| 滚转外环 | 度制，`Kp=0.25`，另乘 30 | 弧度，`Kp=7.5` | 外环物理增益等效 |
| 滚转内环 | 末尾乘 0.01；P/I/D/FF=0.15/0.1/0.0002/0.12 | P/I/D/FF=0.003/0.002/0.000004/0.0024，分别除以 R | 当前发布值约为旧值 2 倍 |
| 构型控制 | 度制外环另乘 30，内环末尾乘 0.01 | 弧度外环 Kp=6，内环 FF/P/I=0.002/0.004/0.004，分别除以 R | 当前发布值约为旧值 2 倍 |
| 俯仰 PID | 度制外环另乘 30，内环末尾乘 0.01 | 弧度外环 Kp=3.6，内环 P/I/FF=0.0055/0.005/0.01，分别除以 R | 当前发布值约为旧值 5 倍 |
| 主从 PID 舵面分配 | 末尾副翼 ×2，升降舵 ×5 | 直接使用上述最终尺度的输出 | 消去重复倍率，物理尺度等效 |
| 滚转阻尼 | 原控制器输出后 mixer 再 ×5 | 换算合入 `k_Clp=0.0003125/R` | 主从本机阻尼物理尺度等效 |
| 滚转参与差动油门 | 使用原滚转输出 | 使用当前滚转输出的 0.5 倍 | 保持差动贡献 |
| 升降舵到副翼交联、刹车 | 最终尺度叠加 | 同样在最终尺度叠加 | 没有跟随主分配重复放大 |
| 偏航、基础油门及最终 PWM 映射／限幅 | 原实现 | 对应源码未变 | 测得默认策略下两路 PWM 相同 |

五项误差积分限幅由 45 换成 `Units::toRadians(45)`。这保持物理积分范围，不是缩小实际允许积分。

残差有两个来源：① 弧度计算与合并增益改变浮点乘加、积分及缩放次序；② 旧等效滚转角乘 `57.3`、俯仰耦合项使用 `/57.3`，当前使用弧度三角函数。这些变化在实数等效尺度之外仍会留下小的数值差，整数截断边界会放大成 1 μs。

## 从机：本机闭环与上级贡献

从机只运行本机俯仰闭环及滚转阻尼；滚转、偏航与油门整体分配由主机生成。两版都在从机把上级贡献与本机贡献相加，再使用本机 PWM 标定映射。

| 路径 | tag | 当前版本 |
| --- | --- | --- |
| 本机俯仰 PID 升降舵 | 本机 PID 输出在 mixer 乘 5 | PID 参数已含 5 倍尺度，mixer 直接使用 |
| 本机俯仰到副翼交联 | 由已乘 5 的本机升降舵生成 | 由当前最终尺度升降舵生成 |
| 本机滚转阻尼 | mixer 乘 5 | 控制器参数已合入倍率 |
| 上级副翼、升降舵前馈、油门、方向舵 | 主机已完成换算，融合只相加 | 同样只相加 |
| 默认三机策略 1 的俯仰目标 | 各从机等于主机目标，无策略 3 升降舵前馈 | 相同 |

扩展策略 2/3 的从机目标系数已按滚转／构型新输出尺度减半；策略 3 的主机升降舵前馈也作对应尺度换算。扩展策略的目标和贡献仍存在浮点残差，不能从默认策略 1 的结果推断逐位一致。

## INDI 单列差异

当前选择 INDI 时，主机给本机及从机的副翼滚转／构型主分配约为 tag 的 2 倍。tag 的副翼 ×2 仅在俯仰选 PID 时执行，当前已经统一 PID/INDI 的副翼尺度。此差异是控制行为变化，不能归入浮点误差，也不能将包含交联、阻尼和刹车的总 PWM 偏移直接乘 2。

以滚转目标 +5°、反馈零、首次更新为例（五路顺序同上）：

| 飞控 | tag INDI PWM | 当前 INDI PWM |
| --- | --- | --- |
| A | 1493 / 1493 / 1500 / 1750 / 1495 | 1486 / 1486 / 1500 / 1750 / 1495 |
| B | 1429 / 1541 / 1500 / 1753 / 1495 | 1359 / 1582 / 1500 / 1753 / 1495 |
| C | 1541 / 1429 / 1500 / 1746 / 1495 | 1582 / 1359 / 1500 / 1746 / 1495 |

INDI 俯仰控制器的标定、限速和内部状态从度换成弧度，实际物理标定保持对应；本次三机策略 1 测得 B 升降舵仍有最大 1 μs 边界残差，A/C 未出现整数差异。本次按用户选择没有恢复旧 INDI 副翼分配。

## 扩展和可复现性

程序另外覆盖 1/3/4/5/7 机及三种策略，每版合计 720,000 次板级控制更新，比较 3,600,000 对整数 PWM。所有扩展组合中，手动整数 PWM 全部相同，PID 最大差为 1 μs。策略 2/3 需在测试中显式覆盖，实际固件默认固定策略 1。未修改生产参数。

同一个 tag 分别编译两份运行三机全场景的自比较，108,000 对板级状态、540,000 对 PWM 及原始浮点 PWM 全部一致。

程序及完整运行方式见 [tools/control_compare/README.md](../tools/control_compare/README.md)。本次使用 MinGW GCC 14.2.0，`-O3 -ffast-math -ffp-contract=off`，C++17。控制／混控及 PWM 输出采用对应版本真实源码，只有硬件接口为空操作；每板控制器与发布历史独立，从机接收本版本主机实际生成的命令。

原始 CSV、完整源码快照、源码 SHA256 清单、统计及差异样例在 `.cache/control-compare/`，自身比较在 `.cache/control-compare-self/`。缓存不纳入 Git，程序可重新生成。本报告更新了此前稀疏采样的观察：旧报告中“默认三机 PID 采样全部相同”只适用于当时的采样点，不能扩展成任意周期均相同。

这是原生数值比较，未烧录或连接硬件，不模拟机间 1/4096 控制量、0.001 rad 目标的协议量化与 UART 延迟，也不包含传感器采样或飞机动力学。整数 PWM 经真实映射及限幅函数得出，但不同目标编译器、数学库、优化选项可能改变边界差异的样本数量；本报告不宣称以上计数就是 Teensy 实机计数。
