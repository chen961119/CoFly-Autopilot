# 2026-10-27 最新工作区与飞行 tag 的控制输出复核

本报告替代上一轮工作区的数值结论。基准为 `20261024-3Airplane-Flight`，实际提交 `528c840b04296e903bf9f42cbf5d01fbae19a33c`；当前 HEAD 为 `125f1bdcef893da291eb6af520c79b90d388ba6e`，计算对象包含当前未提交修改。生产源码和默认参数未因本次复核而修改。

**当前默认参数下，PID 与该 tag 已不一致，差异不再仅为 1 μs。** 默认三机／策略 1 下，A/B/C 最大最终整数 PWM 差分别为 **263 / 181 / 292 μs**；策略 2 为 **284 / 179 / 253 μs**，策略 3 为 **284 / 162 / 254 μs**。这些是本次预设状态序列的采样最大值，不是全状态空间上界。

## 本次发现的有效变化

| 项目 | tag 对应的当前弧度／输出尺度值 | 当前值 | 含义 |
| --- | --- | --- | --- |
| CH7 构型角目标 | ±10° | ±5° | 相同遥控输入生成的构型目标减半 |
| 滚转内环 D | 0.000004 / toRadians(1) ≈ 0.000229183119 | 0.0002 | 比等效值小约 12.73%；不能直接与旧度制 0.0002 比较 |

| configurationControlScale | 1 | 1（现已是 SD 参数） | 默认倍率相同，参数化本身不改变默认输出 |

其余滚转、俯仰、构型内环增益的直接数值是此前换算表达式的 float32 等值写法；这次重点差异是上表实际值变化。新增角速度日志字段、删除未读历史成员、去掉手动构型零输出的除二，以及去掉手动模式下不参与闭环的从机俯仰目标分支，没有引入相应的物理增益变化。

两版源码默认均为三机、策略 1、俯仰 PID、积分启用、空速闭环关闭。五路 PWM min/trim/max 均为 1000/1500/2000 μs，mode 均为 0，rev 为 -1/+1/+1/+1/+1；俯仰目标配平 3°。每版均直接读取并运行自己的默认值，不加载 SD/EEPROM。计算显式配置身份并解锁。mode=0 下油门 0.5 映射为 1750 μs。

当前 `control_modes.cpp` 的构型目标常数已为 5°，附近“相邻飞机相差 10 度”的注释以及部分旧文档尚未同步；本报告按实际执行的 5° 计算。
