# 研究方法与控制演进

本文合并旧仓库快照、论文分析及 2026-10-17～18 的控制专项报告，只保留研究背景和解释历史差异所需的结论。现行模块和行为见 [系统架构](../architecture.md)、[控制架构](../control-architecture.md)；配置操作见 [固件指南](../firmware-guide.md)。

## 论文与现有实现

参考 [Zhu、Zhou、Wang（2025）论文](../references/zhu-2025-morphing-control.pdf)，重点为 PDF 第 5～8 页、式 (16)～(21)、(27)～(39) 和图 6。以下是既有分析的整理，不代表固件已实现论文全部方法。

| 要素 | 论文方法 | 仓库实现与边界 |
| --- | --- | --- |
| 总体框架 | 整体等效姿态与相对构型并行，执行器命令叠加 | 保留姿态和构型控制并行的思想 |
| 整体姿态 | 串级 PI 和等效姿态分配 | 独立姿态/角速度控制器及构型相关固定混控 |
| 构型外环 | 障碍型非线性变增益律 | 线性 P 外环 |
| 构型内环 | 相对角加速度 INDI | 相对角速度 PI，含前馈 |
| 构型分配 | 动态效能矩阵和饱和感知 IWPI | 固定系数；另保留未接入的五体普通 SVD 分配器 |
| INDI 用途 | 相对弯折构型控制 | 本机俯仰升降舵控制 |
| 平台 | 三机 PIXHAWK/PX4 原型 | Teensy 4.1、dRehmFlight 派生的 A～G 固件 |

### 构型 INDI 与补偿思路

以 e 为滤波后的构型角目标减测量值，论文角度外环及加速度参考可写为：

```text
w_c     = K_e * e / (b²-e²)，|e|<b
w_dot_c = K_w * (w_c-w_m)
v_c     = v_f + w_dot_c - w_dot_m_f
delta_aileron = IWPI(B(q,V), v_c)
```

误差接近 b 时增益快速增大，工程实现需限定适用域。执行器与结构模态的带宽分离是增量近似的前提，不能直接把这一构型控制律当作当前俯仰 INDI。

论文还以副翼诱导俯仰力矩前馈叠加相对扭转 PI；三机等效滚转可由各机滚转的正弦和、余弦和求圆均值。这些思想与代码存在关联，但不能据此认定具体坐标、系数和控制器相同。

普通伪逆最小化二范数；IWPI 根据舵面接近饱和边界的程度迭代调整权重，将任务转移给剩余裕度更大的执行器。后续若实现七机动态分配，需要六连接、14 副翼的完整模型，并统一处理构型/姿态任务优先级、舵偏、舵速和执行器故障约束。

## 保留的五体动力学分配模型

入口为 [control_allocation.cpp](../../src/control/control_allocation.cpp)，当前主循环中的初始化和周期调用均已注释。以下描述保留模型的数学结构，不表示它参与当前执行器输出。

```text
M_r(q) * q_ddot + Q_r(q) = B_e(q) * H * delta
A(q) = inverse(M_r(q)) * B_e(q) * H
```

| 矩阵 | 尺寸 | 含义 |
| --- | --- | --- |
| M | 18×18 | 五体完整广义质量矩阵 |
| M_r / Mpi | 10×10 | 三平动、三转动、四铰链自由度的降阶矩阵 |
| B_e | 10×35 | 气动力/力矩到广义力的几何映射 |
| H | 35×20 | 五机每机四通道的静态舵效矩阵 |
| A / Bplus | 10×20 | 执行器到广义加速度的效能矩阵 |

降阶自由度索引为 `{0,1,2,3,4,5,6,9,12,15}`，十个副翼列为 `{0,1,4,5,8,9,12,13,16,17}`。构型任务取 A 的行 `{6,7,8,9}`，组合任务取行 `{3,5,6,7,8,9}`。普通 SVD 伪逆保留大于 `1e-6*max(m,n)*sigma_max` 的奇异值。

重新启用前需复核旧分析指出的 `getQx()` 局部变量遮蔽、旋转矩阵更新顺序、直接求逆的病态保护，以及分别求解后相加引入的任务耦合。这些是保留模型的审查线索，目标验收见 [动态分配需求](../requirements.md#7-动态控制分配需求)，不能当作现行飞行路径的实测故障。

## 旧版对照的主要结论

旧基线为 `86879cc4e03cd4dc8a6271999cb1ac67a1b80b7e`；首轮软件对照对象为 `58aa866c7e4c660ea3812e9002ebb825c87fea1f`，后续报告还包含工作区修订。各轮测试快照不同，不能拼成一次当前版本验收。

对照需分别检查控制器、混控/融合、入口与最终 PWM。必须对齐传感器物理方向、目标、参数、积分和滤波/延迟历史；单个公式或标量对应不能证明整条链等价。

| 历史差异 | 整理后保留的解释 |
| --- | --- |
| 俯仰 PID | 相同有效目标、参数、轴向和历史下，核心串级公式对应；入口、限幅和中位需另算 |
| 旧四机/五机滚转 | 四机曾有未初始化反馈；五机曾命中错误求和分支，不能作为可靠的整体等价基准 |
| 偏航 | 用户曾反向遥控器偏航通道，应按物理输入映射目标和输出；同号注入的差异不等于方向错误，实装排除 rudder |
| 积分与切换 | 旧无积分模式仍可能累积历史或包含偏航积分；现行为本机独立开关，关闭清历史，俯仰算法切换另行重置 |
| INDI 初始化 | 当前以切换时目标重置差分历史，旧从零目标起步可能产生首周期斜率；滤波常数精度也造成微小差异 |
| 主机 INDI 副翼补偿 | 旧路径先用 PID 补偿，再以 INDI 覆盖升降舵；现行补偿使用选中的俯仰算法 |
| 从机手动补偿 | 旧实际升降舵执行上级命令，副翼补偿却取本地 Aele；现行使用收到的完整手动升降舵贡献 |
| 机械配平 | 旧补偿可能包含物理 trim；现行在逻辑域交联，零逻辑贡献不引入 trim 补偿 |
| PWM 基准与约束 | 旧舵面中位 1520、油门基准 1100，与当前统一 1500 不同；限幅顺序、范围和整数转换也不同 |
| 通信与模式 | 旧 50/33 字节命令/状态帧及旧模式字段，不能与当前 40/34 字节布局混用 |
| 滚转阻尼 | 历史统计对应过不同叠加版本，方向须结合逻辑坐标、安装 rev 和实际舵面核对 |

### 已收敛的升降舵与 INDI 方案

2026-10-17 的三机策略 3 前馈曾漏掉 PWM 域到逻辑域的符号转换，随后修正，再随升降舵统一下偏正转换坐标。当前 B 负/C 正前馈与修复后的控制作用一致，公式在 [控制架构](../control-architecture.md#逻辑坐标交联与融合) 维护。

升降舵方向调整最终沿用 `pwm_channel3_rev`，默认由 -1 改为 1；原计划中的新增语义参数、自动翻转保存值和帧版本更换均未实施。旧 SD 值须按同一安装手动调整，见 [方向迁移](../firmware-guide.md#执行器映射与方向迁移)。

2026-10-18 曾采用两端归一化的 INDI 输出和延迟队列，随后回退为内部浮点物理 PWM；出口仍保留 `indiOutput`，统一为 1=1000 μs 的逻辑偏移。配平零点、正斜率 k 和通道3统一范围保留，分段归一化模块及 `allocatePitchCommand()` 已删除。当前公式及模型限制只在 [俯仰 INDI](../indi-variable-naming.md) 维护。

五路 PWM 软件范围已由编译常量改为本机 SD 整数参数，驱动 attach 范围独立；参数合法性与恢复行为见 [参数声明](../parameter-storage.md#参数声明)。

## 历史检查的证据边界

原专项记录描述过主机模拟检查：1/3/4/5/7 机、手动/PID/INDI、策略边界、rev/trim、混控融合、真实命令编解码、INDI 限速/低通/延迟模型、PWM 往返，以及 SD 参数加载和保存。硬件串口、Servo、SD/EEPROM 或时钟使用替身，部分控制结果直接注入；这些检查不构成真实飞行动力学或实板端到端验证。

本次文档清理删除了全部 `docs/validation` 数值结果、源码摘要、补丁及方法文件，同时移除重复专项报告；临时测试程序此前已删除。因此不保留失去复查依据的大量通过计数，也不提供已删除数据的链接。这里只记录历史范围与差异原因，没有在本次重新运行固件构建、控制测试、板上测试或飞行试验。

软件换算检查不能证明舵面实物方向、串口时序、Flash 断电安全、500 Hz 最坏周期或闭环稳定性。后续验证应针对明确的源码版本和配置重新执行，并按 [需求验收矩阵](../requirements.md#14-验证矩阵) 记录相应证据。
